# Rdown — Chrome 应用商店详情页文案（简体中文）

> 复制到 Chrome Web Store Developer Dashboard → Store listing → 语言：中文（简体）

## 一句话价值主张（开篇摘要）

Rdown 把浏览器下载交给本机的全能下载管理器：多线程 HTTP、BT/磁力、m3u8/mpd 流媒体，一键接管、断点续传、失败自动回退。适合需要高速、可管理、可自动化下载的用户。

## 核心功能模块

**自动接管下载**
- 点击下载链接自动发送到 Rdown，浏览器下载无缝取消；发送失败自动回退浏览器原生下载，下载永不丢失
- 需要登录态的站点也能接管：自动透传 Cookie / Referer / User-Agent

**流媒体嗅探与下载**
- 自动发现页面加载的 m3u8 / mpd / 视频 / 音频资源，弹窗一键下载
- 深度搜索：扫描页面脚本中的动态媒体地址；支持清晰度选择与 AES-128 解密

**BT 与磁力链接**
- 点击页面 magnet: 链接直接创建任务；tracker 自动更新；DHT/LPD/PEX 全支持

**智能过滤与自动化**
- 域名/后缀/大小三级黑白名单；嗅探正则规则；文件名模板（${title}/${host}/${date} 等变量）
- 嗅探到符合条件的媒体可自动下载；Alt 点击临时跳过接管；快捷键 Alt+Shift+D 开关

**多服务器与集成**
- 按 URL 规则自动路由到不同的 Rdown 服务器；支持远程实例与 API Token 鉴权
- 下载完成/失败系统通知；图标角标实时显示任务数与本页媒体数

## 隐私说明（商店描述末尾附上）

本扩展只把你发起的下载地址及该请求所需的 HTTP 请求头发送到你本机的 Rdown 服务（默认 127.0.0.1，数据不出本机）；不收集、不上传任何数据给第三方，不含广告与追踪。详见隐私政策。
