이 확장 프로그램은 오픈 소스 다운로드 관리자 Rdown의 공식 브라우저 컴패니언입니다. 브라우저 다운로드를 가로채어 사용자 본인의 컴퓨터에서 실행 중인 로컬 서비스로 넘기므로, 대용량 파일, 동영상, 토렌트를 브라우저 기본 기능 대신 진정한 다운로드 엔진이 처리합니다. 서비스가 꺼져 있으면 자동으로 브라우저로 되돌아가므로 멈추거나 사라지는 일이 없습니다.

✨ 주요 기능
✅ 자동 이관: 브라우저 다운로드를 가로채어 내 PC의 Rdown 관리자로 전송하고, 실패 시 즉시 브라우저로 복귀
✅ 헤더 전달: Cookie, Referer, User-Agent를 자동으로 실어 보내 로그인이 필요한 사이트의 파일도 이관
✅ 미디어 스니핑: 페이지의 m3u8, mpd, 동영상, 오디오 리소스를 자동으로 찾고 동적 주소를 심층 검색, 한 번의 클릭으로 저장
✅ BT와 마그넷: magnet: 링크를 클릭하면 바로 작업이 생성되고 트래커는 자동으로 업데이트됩니다
✅ 스마트 필터와 자동화: 도메인, 확장자, 크기 3단계 필터, 파일 이름 템플릿, 여러 서버로의 URL 라우팅, 자동 저장, 단축키와 알림

🚀 사용 방법
1. 무료 오픈 소스 Rdown 로컬 앱을 설치하고 실행합니다 (기본 http://127.0.0.1:16801)
2. 이 확장 프로그램을 추가하고 옵션 페이지에서 원클릭 연결 테스트를 실행합니다
3. 평소처럼 파일을 받으세요. Rdown이 이어받고, 앱이 꺼져 있으면 브라우저가 처리합니다

🔒 개인정보 및 데이터 보안
• 설정은 브라우저의 chrome.storage에만 로컬로 저장됩니다
• 다운로드 주소와 해당 요청 헤더는 내 PC(127.0.0.1)의 Rdown 서비스로만 전송됩니다
• 데이터 수집 없음, 제3자 전송 없음, 광고 없음, 추적 없음
