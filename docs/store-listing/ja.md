この拡張機能は、オープンソースのダウンロードマネージャー Rdown の公式コンパニオンです。ブラウザのダウンロードを検出し、あなた自身のパソコンで動作するローカルサービスへ引き継ぐため、大きなファイルや動画、トレントをブラウザ標準ではなく本格的なエンジンが処理します。サービスが停止しているときは自動的にブラウザへフォールバックするので、途中で止まることはありません。

✨ 主な機能
✅ 自動引き継ぎ： ブラウザのダウンロードをインターセプトして本機の Rdown マネージャーへ送信、失敗時は即座にブラウザへフォールバック
✅ ヘッダー透過転送： Cookie、Referer、User-Agent を自動で引き継ぐため、ログインが必要なサイトのファイルにも対応
✅ メディアスニファー： ページ内の m3u8、mpd、動画、音声リソースを自動検出し、動的アドレスをディープ検索、ワンクリックで保存
✅ BT とマグネット： magnet: リンクをクリックするだけでタスクを作成、トラッカーは自動更新
✅ スマートフィルターと自動化： ドメイン、拡張子、サイズの三段階フィルター、ファイル名テンプレート、複数サーバーへの URL ルーティング、自動保存、ショートカットと通知

🚀 使い方
1. 無料のオープンソース Rdown ローカルアプリをインストールして起動（既定 http://127.0.0.1:16801）
2. この拡張機能を追加し、オプションページでワンクリック接続テストを実行
3. いつも通りダウンロードするだけ。Rdown が引き継ぎ、アプリ停止時はブラウザが処理します

🔒 プライバシーとデータ安全
• 設定はブラウザ内の chrome.storage にのみローカル保存されます
• ダウンロード URL とそのリクエストヘッダーは、あなたの本機（127.0.0.1）の Rdown サービスにのみ送信されます
• データ収集なし、第三者への送信なし、広告なし、トラッキングなし
