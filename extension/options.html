Rdown 连接器设置

语言

切换语言后扩展将自动重载，使所有界面生效

服务器

Rdown 后端地址，默认 http://127.0.0.1:16801（下方多服务器列表为空时生效）
若后端"设置 → API Token"非空，需在此填写相同令牌

多服务器（URL 路由）

按顺序匹配「下载地址+文件名」，首个命中的服务器接收任务；规则为 * 或留空的项是默认服务器；列表第一项兜底
名称地址TokenURL 规则

接管规则

同时匹配页面域名与下载文件域名；* 匹配任意字符
m3u8 / mpd 流媒体地址始终接管，不受后缀过滤影响

功能

按住 Alt 点击下载可临时跳过接管（旁路）

嗅探与媒体

仅命中规则的 URL 会进入嗅探列表；* 匹配任意字符，? 匹配单个字符
可用变量：${title} 页面标题、${fileName} 原文件名（不含扩展名）、${ext} 扩展名、${host} 站点域名、${date} 日期（YYYYMMDD）
